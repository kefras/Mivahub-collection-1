# MIVA COLLECTION HUB

Miva Collection Hub is a **responsive fashion website** built to showcase clothing products, events, and brand information for a fashion house. The project demonstrates clean frontend structure, responsive layouts, and user-focused design using core web technologies.

## 🚀 Project Overview
This project was developed as a **frontend web project** to practice building a multi-page website with structured navigation, product showcases, and basic interactivity.

The website highlights:
- Brand identity
- Featured fashion products
- Upcoming fashion events
- Contact and navigation flow

## 🛠️ Tech Stack
- **HTML5** – Semantic structure and page layout  
- **CSS3** – Styling, layout, and responsiveness  
- **JavaScript** – Basic interactivity (buttons and UI behavior)

## 📂 Pages Included
- **Home** – Hero section, brand introduction, featured products  
- **About** – Brand and fashion philosophy  
- **Products** – Product showcase and pricing  
- **Events** – Fashion events and announcements  
- **Contact** – Contact details and brand communication  

## ✨ Key Features
- Responsive navigation menu  
- Product grid layout  
- Fashion showcase section  
- Scrolling marquee for upcoming events  
- Clean and simple UI design  
- Multi-page website structure  

## 👨‍💻 My Role (Frontend Developer)
- Designed and structured all web pages using HTML  
- Styled layouts and components with CSS  
- Implemented responsive sections and product grids  
- Added basic JavaScript interactivity  
- Ensured clean navigation and user flow
